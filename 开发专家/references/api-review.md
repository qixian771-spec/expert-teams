# 接口与数据结构评审清单

> 使用说明：开发专家评审接口契约与数据字段时使用。

## 一、接口契约评审
| 核查点 | 说明 | 结论(✓/△/✗) |
|-------|------|-------------|
| 路径与命名 | RESTful / 语义清晰、版本前缀 | |
| 方法与幂等 | GET/POST/PUT/DELETE，写操作是否幂等 | |
| 入参校验 | 必填、类型、范围、边界 | |
| 出参结构 | 字段稳定、分页、错误包装 | |
| 错误码 | 统一错误码与文案，可定位 | |
| 鉴权与权限 | token / 角色 / 数据权限 | |
| 限流与超时 | 默认超时、限流策略 | |
| 兼容性 | 新增 / 修改是否破坏旧端 | |

## 三、版本与迁移
- 新增字段是否向后兼容（旧端忽略未知字段）？
- 废弃字段是否有过渡期与下线计划？
- 数据迁移方案（存量数据如何处理）？
