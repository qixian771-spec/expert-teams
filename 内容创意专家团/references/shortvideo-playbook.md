# 短视频方法论 Playbook（短视频创意专家）

> 深度核心：按平台算法与留存规律设计，不是拍脑袋写脚本。

## 一、平台机制（先懂规则再做内容）
- **流量池分级**（抖音）：初始 300–500 曝光 → 完播率/互动率达标 → 进更大流量池。
- **完播率是王道**：尤其前 3 秒决定生死；5 秒留存同样关键。
- **互动信号**：点赞/评论/转发/关注/主页访问，都会被加权。
- 结论：**为"看完"和"互动"而设计，不是为"讲清楚"而设计。**

## 二、爆款结构（钩子→留存→转化）
```
钩子(0-3s) → 痛点/冲突(3-8s) → 反转/方案(8-20s) → 证据(20-25s) → CTA(25-30s)
```

## 三、留存曲线优化（中段不塌）
- 每 **3 秒**给一个信息点 / 反转 / 新画面，防止划走。
- 信息密度前高后稳；把最炸的点前置。
- 用"悬念—兑现"循环吊着用户看完。

## 四、钩子库（前 3 秒，挑一个最强的）
- 提问式、反常识、悬念式、利益前置、身份绑定、冲突开场、结果前置。

## 五、封面公式
- 大字报（核心利益一句话）、前后对比、悬念留白、真人表情。

## 六、BGM / 节奏点
- BGM 情绪曲线对齐结构；鼓点/重音卡在转场与反转处。

## 七、发布与放大
- 标题带 2–3 个精准标签 + 1 个热点标签；
- 发布时间匹配受众在线高峰；
- 达标后可用 Dou+ / 千川放大已验证的爆款。

## 八、自检
- [ ] 前 3 秒钩子够强吗（够反常识/够利益/够悬念）？
- [ ] 每 3 秒有信息点吗，中段会塌吗？
- [ ] 结构完整（钩子→…→CTA）吗？
- [ ] 有没有引导互动（评论/关注）？
- [ ] 时长匹配平台与目标吗？
