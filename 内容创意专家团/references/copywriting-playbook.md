# 文案方法论 Playbook（文案专家）

> 深度的核心：不是"写文案"，而是"按打法写"。按场景选框架、套公式、配平台。

## 一、 persuasion 框架（按场景选型）
| 框架 | 结构 | 适用 |
|------|------|------|
| **AIDA** | 注意→兴趣→欲望→行动 | 广告、详情页、短视频 |
| **PAS** | 痛点→放大→方案 | 痛点驱动的产品、种草 |
| **4U** | Urgent紧迫/Unique独特/Useful有用/Ultra-specific超具体 | 标题、海报、slogan |
| **FAB** | 特性→优势→利益 | 产品卖点、功能介绍 |

## 二、标题公式（直接套用）
- **数字式**：`3个方法，让你XX翻倍`
- **疑问式**：`为什么你XX总是失败？`
- **反差式**：`我用最笨的方法，赚到了最多的钱`
- **痛点式**：`还在被XX折磨？`
- **悬念式**：`直到我发现这个，才明白……`
- **身份代入式**：`程序员/宝妈必看`

## 三、钩子公式（前 3 秒 / 首句，决定生死）
- **反常识**：`其实XX是错的`
- **制造好奇**：`我赌你不知道这个`
- **直击痛点**：`如果你也XX，这条别划走`
- **身份绑定**：`做XX的一定要看`
- **利益前置**：`看完这条，你能省XX`

## 四、平台风格（一稿多投必死，按平台改写）
| 平台 | 风格 | 要点 |
|------|------|------|
| **抖音** | 短平快、口语、玩梗 | 节奏快、强钩子、强 CTA |
| **小红书** | 种草、真实感、干货清单 | 第一人称、emoji、避坑/合集 |
| **公众号** | 深度、逻辑、情绪 | 观点+论证+金句 |
| **视频号** | 正能量、大众化 | 通俗、情感共鸣 |

## 五、广告语 / Slogan
- 押韵（`怕上火，喝XX`）、对仗、反差、行动指令、可记忆（≤10字）。

## 六、CTA 公式
`紧迫感 + 低门槛 + 明确动作` → `现在点下方，免费领，仅限今天`

## 七、自检（产出前过一遍）
- [ ] 首句/前3秒有钩子吗？
- [ ] 用了哪个框架，结构完整吗？
- [ ] 利益点具体吗（数字/结果）？
- [ ] 符合目标平台风格吗？
- [ ] CTA 明确吗？
