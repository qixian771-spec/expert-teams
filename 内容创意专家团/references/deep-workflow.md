# 深度端到端工作流：调研 → 生成 → 评分 → 迭代 → 产出

> 每一步都有产物与达标线，不达标不进下一站。这是"深度"与"模板堆"的区别。

## Step 0 · 输入对齐（不齐先追问）
- 产品/主题、平台、目标（涨粉/转化/品宣）、受众、时长、风格参考。
- **缺任一关键项，先问清楚再往下。**

## Step 1 · 爆款调研（并行子 agent）
- 启动 2–3 个并行子 agent（web search），拆解同类爆款：
  - 高赞标题/钩子句式、内容结构、文案风格、封面类型、BGM、数据量级。
- 产出：`调研报告.md`（同类爆款的钩子库 + 结构库 + 文案范式 + 封面范式）。
- **达标线**：≥5 个同类爆款样本，提炼出可复用的钩子与结构。

## Step 2 · 多变体生成
- 基于两套 playbook + 调研结果，一次产出 **5–10 个变体**：
  - 不同钩子 × 不同结构 × 不同平台风格组合。
- 产出：`变体清单.md`（每条含钩子/结构/标题/首句/CTA/分镜要点）。
- **达标线**：≥5 个差异化变体（不是同一句换皮）。

## Step 3 · 评分（跑脚本）
- 运行：`python scripts/score_content.py 变体清单.md`
- 维度：钩子强度、结构完整、利益具体、情绪/共鸣、CTA 明确、平台匹配。
- 产出：`评分表.md`（每个变体各维度得分 + 总分 + 排名）。
- **达标线**：自定义（默认总分 ≥80 视为可产出）。

## Step 4 · 迭代（低分打回）
- 低于达标线的变体：按最低分维度定向重写（钩子弱换钩子、CTA 弱改 CTA）。
- 重新评分，直到 ≥N 个达标（默认 3 个）。

## Step 5 · 产出与移交
- 产出 TOP 变体的完整内容：**脚本 + 文案 + 分镜 + 封面方向 + 音频方案**。
- 视觉/封面/图标 → 移交「创意多媒体专家团」或调用图像生成。
- 实际剪辑/配音 → 借助剪映/PR/配音工具，本团队产出执行脚本。

## 产物清单
```
{topic}/
  调研报告.md      # 同类爆款拆解
  变体清单.md      # 5-10 个变体
  评分表.md        # score_content.py 输出
  最终脚本.md      # TOP 变体的完整可用内容
```
