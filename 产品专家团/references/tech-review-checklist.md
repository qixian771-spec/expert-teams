# 技术方案评审清单

> 使用说明：开发专家评审技术方案时逐项核对，输出"可行 / 需调整 / 有风险"结论。

## 一、方案概述
- 目标与背景（对应哪个需求 / PRD 条目）
- 核心思路（一句话 + 架构图 / 流程图）

## 二、评审维度
| 维度 | 核查点 | 结论(✓/△/✗) | 备注 |
|------|-------|-------------|------|
| 需求一致性 | 是否覆盖 PRD 全部功能点，有无范围变更 | | |
| 技术依赖 | 内部服务 / 三方 SDK / 基础设施依赖是否明确 | | |
| 接口设计 | 接口契约、错误码、幂等、鉴权是否合理 | | |
| 数据结构 | 表结构 / 字段口径 / 索引 / 迁移方案 | | |
| 兼容性 | 新老版本、多端、浏览器 / 机型兼容 | | |
| 性能 | 预估 QPS / 耗时 / 容量，是否有瓶颈 | | |
| 安全 | 鉴权、越权、注入、敏感数据 | | |
| 可观测 | 日志、监控、告警、埋点 | | |
| 可运维 | 灰度、回滚、配置化 | | |
