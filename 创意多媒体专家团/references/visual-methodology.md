# 视觉方法论（视觉/UI 专家共用）

> 深度核心：按设计原理做视觉，不是凭感觉。

## 一、配色
- **60-30-10 法则**：主色 60% + 辅助色 30% + 强调色 10%。
- **对比度**：正文与背景对比度 ≥ 4.5:1（WCAG AA），大字 ≥ 3:1。
- 强调色只给 CTA / 关键信息，别到处用。

## 二、排版四原则（CRAP）
- **对比 Contrast**：重点要大/粗/亮。
- **重复 Repetition**：同级元素样式统一。
- **对齐 Alignment**：所有元素对齐到网格。
- **亲密性 Proximity**：相关的靠近，无关的拉开。

## 三、字体层级
- 一级标题 / 二级标题 / 正文 / 辅助 共 ≤4 级；字阶比例 1.25–1.5。
- 中文正文 ≥14px（移动端），行高 1.5–1.75。

## 四、构图 / 视觉动线
- 移动端遵循 **F 型 / Z 型** 阅读动线，把钩子放在起点。
- 竖屏短视频：关键信息放**中上 1/3**，避开底部被 UI 遮挡区。
- 留白即信息：别把版面塞满。

## 五、品牌一致性
- 所有物料复用同一套色彩/字体/圆角/图形语言（对齐 visual-design-template）。
- 系列内容用固定版式骨架，提升识别度与生产效率。

## 六、常见翻车
- 字体侵权（用未授权商用字体）→ 换开源字体（思源黑/宋、阿里巴巴普惠体等）。
- 一图多投（不同平台比例不同）→ 按 platform-specs 出多尺寸。
- 对比度不足 → 小字看不清。
